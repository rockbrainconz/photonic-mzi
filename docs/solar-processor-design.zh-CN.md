# 非相干日光矩阵乘加：理论与光处理器实现

[English](solar-processor-design.md) | [简体中文](solar-processor-design.zh-CN.md)

> 状态：`experiment/solar-incoherent` 分支的实验设计说明。本文先固定理论、系统边界、
> 代码语义和验证标准；教学动画不属于当前阶段。

## 1. 结论先行

日光可以作为**非相干功率载波**参与矩阵乘加。它不需要像相干 MZI 处理器那样保持
复振幅相位；乘法由强度透过率完成，加法由探测器对功率的空间汇聚完成。

但这个结论有严格限定：

1. 输入通道必须共享可被参考探测器代表的公共日照因子；
2. 输入、权重与探测链必须工作在线性区；
3. 正负值必须采用双轨表示，且两轨同时曝光；
4. 光谱和空间响应不能随通道或时间产生未校准的非公共变化；
5. 被动扇出必须满足总功率守恒，不能把一份输入免费复制成多份满功率输出；
6. 各通道在探测器上的互相干交叉项必须低于目标精度；
7. 日光只为光学信号提供能量，不代表完整可编程系统不使用电力。

因此本方案不是“把日光接入现有 MZI”。它是一台独立的**非相干强度交叉阵列**。

## 2. 系统边界

```text
日光
  │
  ├─ 集光 / 带通滤光 / 匀光 ────────────────┐
  │                                           ├─ 参考探测器 Pref
  └─ 输入强度调制 z+、z-
           │
           ├─ 被动均匀扇出 f = eta_f / m
           │
           ├─ 权重透过率 W+、W-
           │
           ├─ 行汇聚
           │
           └─ 正负探测器 P+、P-
                         │
                         └─ 差分、参考归一化、标度恢复 → y
```

光学核心的边界是从匀光后的日光到 `P+`、`P-`、`Pref` 三组功率。TIA、差分电路、
ADC、控制器以及调制器驱动属于外围电子系统。

## 3. 信号约定与完整推导

目标是：

```text
y = Mx + b
```

把偏置写成额外输入：

```text
A = [M  b]
z = [x; 1]
y = Az
```

令：

```text
alpha = max_ij |A_ij|              # 权重标度
beta  = beta_FS                    # 已声明的固定输入满量程
W     = A / alpha
u     = z / beta
```

于是 `|W_ij|<=1`、`|u_j|<=1`，可分解为非负量：

```text
W = W+ - W-
u = u+ - u-
```

其中 `W+、W-、u+、u-` 全在 `[0,1]`。令均匀被动扇出的总效率为
`eta_f`、输出行数为 `m`，则每行分支比例为 `f=eta_f/m`。理想双轨输出为：

```text
P+ = C(t) f [W+u+ + W-u-]
P- = C(t) f [W+u- + W-u+]
```

相减得到：

```text
P+ - P-
= C(t) [(W+ - W-)(u+ - u-)]
= C(t) Wu
= C(t) f Az / (alpha beta)
```

若同时参考探测器输出 `Pref=C(t)`，则：

```text
y = alpha beta (P+ - P-) / (f Pref) = Az = Mx + b
```

这就是当前理想模型能够在浮点误差内与 NumPy 一致的完整证据链。

### 3.1 固定满量程与逐向量 AGC

真实输入编码器通常使用在校准阶段确定的固定 `beta_FS`。若
`max|z_j| > beta_FS`，硬件必须饱和、裁剪或拒绝该输入；小信号则使用更少的
光子。代码中的 `input_full_scale=beta_FS` 对应这种模式。

`input_full_scale=None` 会为每个向量单独选择 `beta=max|z_j|`。这不是免费的
数学操作，而是显式的自动增益控制（AGC）：每次曝光都必须知道输入最大值、重新设置
编码器，并把 `beta` 传给解码器。它适合验证代数，但若不计入这条控制路径，不能
据此推断小信号的光子效率。含偏置时，增广输入具有 `z0=1`，所以固定满量程至少为 1。

### 3.2 被动可实现性与功率守恒

所有掩模透过率小于等于 1 只是必要条件，并不足以保证被动可实现。一般扇出分支
`s_ij` 必须满足：

```text
s_ij >= 0,   sum_i s_ij <= eta_j <= 1
```

当前实现使用 `s_ij=f=eta_f/m`。因此在固定增益失配和探测噪声之前：

```text
sum_i (P_i+ + P_i-) <= C(t) eta_f sum_j |u_j|
```

权重掩模只能进一步衰减分支功率。解码器恢复已知的 `1/f` 数值标度，但不能恢复
已经丢失的光子；散粒噪声必须按衰减后的实际探测功率计算。固定矩阵可以采用非均匀
分光提高利用率，但实测的 `s_ij` 必须进入有效矩阵。如果改用 `m` 块独立受光、
独立调制的输入副本，就必须把随副本数增长的受光面积、总入射日光功率和控制资源
列入预算，不能称为“免费扇出”。
`eta_f` 指参考分光之后的计算路径效率；单独归一化的参考功率不计入计算输出上界，
但从入射日光换算为瓦特时必须计入参考抽头损耗。

## 4. 参考归一化定理

### 4.1 可以消除什么

假设同一次曝光的所有计算功率都乘以同一个正标量 `C(t)`，并且参考通道满足：

```text
Pref = k C(t)
```

其中 `k` 是已知常数，那么除以 `Pref` 可以精确消除 `C(t)`。云层遮挡、太阳高度变化
或集光效率缓慢变化，只有在它们对所有计算通道表现为同一个乘数时才属于这种情况。

### 4.2 不能消除什么

若第 `j` 个输入具有独立增益 `g_j(t)`，或第 `(i,j)` 个权重具有响应 `h_ij(t)`：

```text
P_i ∝ sum_j h_ij(t) g_j(t) W_ij u_j
```

单个 `Pref` 只能提供一个标量，无法恢复全部 `g_j` 和 `h_ij`。因此参考归一化不能
消除局部阴影、通道匀光误差、权重色散、探测器不匹配或正负臂失衡。

### 4.3 必要工程条件

- 参考、正轨和负轨必须**同时采样**；顺序曝光会把天气变化混进差分结果。
- 参考光路必须和计算光路共享集光、滤光和主要温漂路径。
- 参考探测器必须保持在线性、非饱和、正信号区域。
- 参考归一化后的尺度仍需通过已知的 `alpha`、`beta`、扇出比例 `f` 和参考
  增益 `k` 恢复。

### 4.4 有噪声比值的偏差

精确相消假设差分量 `D=P+-P-` 和参考量 `R=Pref` 都无噪声。若差分、参考误差
分别为零均值的 `n_D`、`n_R`，实际估计量为：

```text
y_hat = (alpha beta / f) (D + n_D) / (C + n_R)
```

当真实输出非零且噪声较小时，一阶相对误差约为 `n_D/D - n_R/C`；二阶近似偏差为：

```text
Var(n_R)/C^2 - Cov(n_D,n_R)/(D C)
```

因此“参考读数仍为正”不是精度保证。实验必须先做暗场扣除，让参考远离零点和饱和，
报告参考 SNR，并让参考与计算路径在光谱、偏振、孔径和积分时间上匹配。真实输出接近
零时应报告绝对误差或满量程误差，而不是相对误差。

## 5. 宽带日光的严格模型

真实探测器积分的是波长而不是单一标量。一般形式为：

```text
P_i(t) = sum_j integral S_j(lambda,t)
                         T_ij(lambda,t)
                         R_i(lambda,t)
                         u_j d_lambda
```

其中：

- `S_j`：第 `j` 个输入位置的日光谱功率；
- `T_ij`：输入调制器、扇出和权重单元的联合透射；
- `R_i`：探测器及其前置滤光的光谱响应。

定义实测有效矩阵：

```text
M_eff(t)[i,j] = integral S_j(lambda,t) T_ij(lambda,t) R_i(lambda,t) d lambda
```

单一标量参考严格有效的条件是：

```text
M_eff(t) = c(t) M0
```

建议用以下不可分离误差直接检验：

```text
epsilon_spec(t) = min_c ||M_eff(t) - c M0||_F / ||M0||_F
```

太阳光谱形状、器件色散、偏振或通道响应若随时间改变，得到的是 `M_eff(t)x`，单个
参考通道不能把它恢复成固定的 `M0 x`。行、通道、偏振或波段参考可以补偿某些结构化
误差，但会增加探测器和校准资源。

当前代码的 `spectral_weight_error` 只表示选定滤光条件下，每个权重的**波长积分等效
固定误差**。它不是逐波长传播模型，也不能预测天气、太阳高度或偏振变化下的
`epsilon_spec(t)`。真实滤光片选型必须等以后加入 `S(lambda)`、`T(lambda)`、
`R(lambda)` 数据后再做。

## 6. 非相干功率相加的成立条件

该处理器不需要受控相位，但“日光非相干”不能直接等同于“交叉项为零”。输入 `j`
和 `k` 的光场耦合到同一探测器时，一般功率为：

```text
P_i = sum_j |h_ij|^2 I_j
    + sum_(j != k) 2 Re[h_ij h_ik* Gamma_jk]
```

`Gamma_jk` 是光经过集光、滤光、分束和传播后的互相干函数。只有交叉项在探测面积和
积分时间内小到低于目标精度时，前面的强度交叉阵列公式才成立。可实现条件包括：

- 使用互不相干的源像素；
- 让各贡献落在同一光电二极管的不同、不重叠区域，由光电流完成求和；
- 路径延迟显著超过滤光后的相干时间；
- 使用足够多的空间/时间模式平均残余条纹。

宽带日光通常具有很短的时间相干长度，但窄带滤光会延长它；同一空间模式分束后的副本
也可能保持互相干。台架必须扫描路径差、孔径和滤光带宽，实测条纹可见度或输出方差。
`Gamma_jk ~= 0` 应当是验收结果，而不是从“日光”二字自动得到的假设。

## 7. 双轨光学布局

每个逻辑输入包含 `u+`、`u-` 两个强度通道。每个权重包含 `W+`、`W-` 两个非负
透过率。对第 `i` 个输出，需要两只同时工作的探测器：

| 探测器 | 汇聚的乘积 |
|---|---|
| 正轨 `P_i+` | `W_ij+ u_j+` 与 `W_ij- u_j-` |
| 负轨 `P_i-` | `W_ij+ u_j-` 与 `W_ij- u_j+` |

一个直接的自由空间实现是在二维调制平面上为每个 `(i,j)` 放置四个子像素，再用柱面
透镜或微透镜阵列把同一输出行汇聚到成对光电二极管。所有四类乘积必须来自同一次曝光。

均匀扇出在权重衰减前只把每条输入轨的 `eta_f/m` 功率送向一个输出行。硬件代价是
约四倍权重单元和两倍输出探测器；这是任意四象限实数运算换来的确定性开销。资源数量
按 `O(mn)` 增长，且每个分支的可用光子数随扇出数增加而下降。

## 8. 三种硬件实现等级

### 8.1 全被动固定算子

- `M`：印刷灰度片、金属薄膜或固定透射掩模；
- `x`：自然场景、静态透明片或其他光学传感输入；
- 输出：保留为双轨光功率，或由零偏光电二极管读取。

无源光学核心可不需要外部电力，但矩阵不可动态修改，数字输出通常仍需要电子读出。

### 8.2 固定矩阵、可编程输入

- 固定权重掩模保存 `M`；
- LCD、DMD 或其他强度调制器写入 `x`；
- 适合固定模型推理或固定变换。

这一级需要输入调制器驱动、探测器前端和控制电路。

### 8.3 全可编程处理器

- 一块调制器编码输入；
- 另一块 SLM 编码权重；
- TIA、差分、参考归一化和 ADC 输出数值。

这是当前软件 API 最接近的硬件形态，也是用电最多、校准最复杂的一种。它仍然可以把
乘法和空间累加留在光学域，但不能称为“零耗电计算”。

## 9. 用电与能量边界

| 部件 | 外部用电 |
|---|---|
| 日光、固定透镜、滤光片、扩散片、固定掩模 | 可无源 |
| LCD/DMD/SLM 及其驱动 | 需要 |
| 零偏光电二极管 | 可由光产生电流，但实用读出仍需外围电路 |
| TIA、差分电路、参考除法、ADC | 需要 |
| 温控、太阳跟踪、自动校准 | 通常需要 |

当前模型使用归一化功率单位，没有瓦特、曝光时间、调制器能耗或 ADC 能耗，不能计算
J/MAC。后续只有建立绝对光功率和完整电气功耗清单后，才能比较日光、激光和电子方案。

## 10. 精度与光子预算

若探测器接收的光谱功率为 `P_i(lambda)`、积分时间为 `tau`、量子效率为
`eta_q(lambda)`，平均探测光子数为：

```text
N_i = tau integral eta_q(lambda) P_i(lambda) lambda/(h c) d lambda
```

独立泊松正负轨满足：

```text
Var(N+ - N-) = N+ + N-
```

因此只考虑泊松散粒噪声，探测到 `N_gamma` 个光子时：

```text
SNR ≈ sqrt(N_gamma)
```

理想情况下，约 `b` bit 的相对分辨率至少要求量级：

```text
N_gamma ≳ 2^(2b)
```

这是乐观下界。双轨结果接近零时，两个较大功率相减，定义消减因子：

```text
kappa = (P+ + P-) / |P+ - P-|
```

`kappa` 越大，相对误差越容易被放大；再加上参考通道噪声、暗电流、杂散光和量化误差，
实际需要的光子数会更高。因此实验评价应同时报告绝对误差、满量程误差和消减因子，
不能只在真实结果接近零时报告相对误差。

`photons_per_unit` 只实现归一化泊松基线。没有 `P(lambda)`、`tau`、受光面积、
光学效率和量子效率，就不能换算为瓦特。当前还没有暗计数、探测器 NEP/带宽、饱和，
以及太阳热光的光子聚束或其他过剩强度噪声模型。

## 11. 校准流程

建议按以下顺序表征真实原型：

1. **暗场**：遮光测量每只探测器的偏置、读出噪声和参考比值偏差；
2. **量程与线性度**：确定固定输入满量程以及参考、正轨、负轨的非饱和范围；
3. **功率守恒**：测量扇出比例、总输出/输入功率比和各路径插损；
4. **互相干检查**：扫描路径差、孔径和滤光带宽，测量残余条纹；
5. **输入平场**：逐通道打开单位输入，测量 `g_j` 和局部遮挡敏感度；
6. **权重 LUT**：逐单元扫描灰度码，建立指令到有效透过率的查找表；
7. **双轨平衡**：表征差分臂失配和零输出消减比；
8. **光谱检查**：在多个谱形、偏振和滤光带宽下重复矩阵表征；
9. **端到端矩阵**：用基向量逐列测量 `M_eff`，再用未参与校准的随机向量验证；
10. **户外复测**：跨照度、云量、太阳高度和温度检查误差是否仍在验收范围。

静态校准不能消除曝光期间变化的局部遮挡、谱形漂移或独立探测噪声。

## 12. 软件实现与物理边界对应

`IncoherentSolarProcessor` 把处理链显式拆成三段：

```python
powers = solar.optical_powers(x, ideal=False)  # 无源光学传播：P+、P-、Pref
observed = solar.detect(powers, ideal=False)   # 光子计数与探测/参考读出噪声
y = solar.decode(observed, normalize=True)    # 差分、参考归一化、标度恢复
```

便捷接口只是组合：

```python
y = solar.read(x, ideal=False, normalize=True)
```

这层分离具有两个目的：

- 防止把探测器噪声错误地注入光传播域；
- 允许把真实硬件测得的 `P+、P-、Pref` 封装为 `SolarPowerReadout` 后复用同一解码器。

参数与物理意义：

| 代码参数 | 物理代理 | 当前限制 |
|---|---|---|
| `fanout_efficiency` | 输入轨到全部输出行的总被动扇出效率 | 默认均匀 `m` 路分配 |
| `input_full_scale` | 固定硬件输入满量程；`None` 表示逐向量 AGC | 不模拟裁剪和 AGC 控制能耗 |
| `irradiance` | 平均参考光功率标度 | 归一化单位，不是瓦特 |
| `common_fluctuation` | 每次曝光公共照度变化 | i.i.d.，无时间相关 |
| `spatial_nonuniformity` | 固定输入通道增益 | 未建二维匀光场 |
| `spectral_weight_error` | 固定波长积分权重误差 | 非逐波长 |
| `differential_gain_error` | 固定正负探测臂增益差 | 未建非线性和饱和 |
| `photons_per_unit` | 泊松光子计数换算 | 未从波长、功率、时间推导 |
| `detector_noise`、`reference_noise` | 背景扣除后的加性读出噪声 | 未分解 TIA、暗电流和 ADC |

真实硬件读数复用 `decode()` 时，必须与处理器使用同一扇出比例和输入标度约定。

## 13. 实验阶段与验收条件

### 阶段 A：软件与代数

- 任意实矩阵、实输入、偏置和批量输入与 NumPy 一致；
- 所有探测前功率非负，所有编程透过率在 `[0,1]`；
- 总输出轨功率满足显式的被动扇出守恒上界；
- 固定满量程模式会拒绝超量程输入，AGC 模式会显式携带逐向量标度；
- 公共照度变化在无噪声条件下被参考通道精确消除；
- 固定通道误差和动态探测噪声具有不同、可测试的统计语义。

### 阶段 B：受控非相干光源台架

- 先用 LED 或太阳模拟器，不直接进入户外；
- 验证双轨、参考归一化、线性区和校准流程；
- 报告基向量测得的 `M_eff`、随机向量误差和重复性。

### 阶段 C：真实日光

- 同时记录参考照度、谱形代理、温度和天气；
- 比较归一化前后误差；
- 单独分析公共波动、空间不均匀和光谱变化；
- 只有跨条件重复结果稳定后，才讨论有效 bit 或能效。

### 量化验收指标

具体阈值取决于目标应用，必须在采集数据前声明；以下测量量不能省略：

| 边界 | 指标 |
|---|---|
| 被动光学核心 | `sum(P+ + P-) / [C eta_f sum|u|]` 与插入损耗 |
| 非相干求和 | 最坏路径组合的残余条纹可见度或互相干度 |
| 矩阵保真度 | 基向量得到的 `||M_meas-c M0||_F / ||M0||_F` |
| 光谱稳定性 | 不同测试谱形下 `epsilon_spec(t)` 的分布 |
| 共模抑制 | 照度扫描时归一化前后输出波动之比 |
| 双轨消减 | 指令输出为零时的 `|P+-P-|/(P++P-)` |
| 线性度 | 已声明输入范围内相对满量程的最大残差 |
| 精度 | 满量程 RMSE 或 ENOB 随照度、积分时间的曲线 |
| 重复性 | 随时间、温度、太阳高度和云量的漂移 |

随机验证向量必须与标定 `M_eff`、选择校正参数的数据分离。

## 14. 当前不做的工作

- 不为日光后端制作动画或 GIF；
- 不把日光模型塞进相干 MZI 类；
- 不声称零耗电、商用精度、TOPS 或能效优势；
- 不在缺少逐波长器件数据时选择真实滤光片；
- 不用理想浮点一致性代替硬件证据。
