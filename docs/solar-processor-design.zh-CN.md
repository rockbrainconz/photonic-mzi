# 非相干日光矩阵乘加：理论与光处理器实现

[English](solar-processor-design.md) | [简体中文](solar-processor-design.zh-CN.md)

> 状态：`experiment/solar-incoherent` 分支的实验设计说明。本文先固定理论、系统边界、
> 代码语义和验证标准；教学动画不属于当前阶段。

## 1. 结论先行

日光可以作为**非相干功率载波**参与矩阵乘加。它不需要像相干 MZI 处理器那样保持
复振幅相位；乘法由强度透过率完成，加法由探测器对功率的空间汇聚完成。

但这个结论有严格限定：

1. 输入通道必须共享可被参考探测器代表的公共日照因子；
2. 输入、权重与探测链必须工作在线性区；
3. 正负值必须采用双轨表示，且两轨同时曝光；
4. 光谱和空间响应不能随通道或时间产生未校准的非公共变化；
5. 日光只为光学信号提供能量，不代表完整可编程系统不使用电力。

因此本方案不是“把日光接入现有 MZI”。它是一台独立的**非相干强度交叉阵列**。

## 2. 系统边界

```text
日光
  │
  ├─ 集光 / 带通滤光 / 匀光 ────────────────┐
  │                                           ├─ 参考探测器 Pref
  └─ 输入强度调制 z+、z-
           │
           ├─ 空间复制 / 扇出
           │
           ├─ 权重透过率 W+、W-
           │
           ├─ 行汇聚
           │
           └─ 正负探测器 P+、P-
                         │
                         └─ 差分、参考归一化、标度恢复 → y
```

光学核心的边界是从匀光后的日光到 `P+`、`P-`、`Pref` 三组功率。TIA、差分电路、
ADC、控制器以及调制器驱动属于外围电子系统。

## 3. 信号约定与完整推导

目标是：

```text
y = Mx + b
```

把偏置写成额外输入：

```text
A = [M  b]
z = [x; 1]
y = Az
```

令：

```text
alpha = max_ij |A_ij|              # 权重标度
beta  = max_j  |z_j|               # 每次输入的编码标度
W     = A / alpha
u     = z / beta
```

于是 `|W_ij|<=1`、`|u_j|<=1`，可分解为非负量：

```text
W = W+ - W-
u = u+ - u-
```

其中 `W+、W-、u+、u-` 全在 `[0,1]`。理想双轨输出为：

```text
P+ = C(t) [W+u+ + W-u-]
P- = C(t) [W+u- + W-u+]
```

相减得到：

```text
P+ - P-
= C(t) [(W+ - W-)(u+ - u-)]
= C(t) Wu
= C(t) Az / (alpha beta)
```

若同时参考探测器输出 `Pref=C(t)`，则：

```text
y = alpha beta (P+ - P-) / Pref = Az = Mx + b
```

这就是当前理想模型能够在浮点误差内与 NumPy 一致的完整证据链。

## 4. 参考归一化定理

### 4.1 可以消除什么

假设同一次曝光的所有计算功率都乘以同一个正标量 `C(t)`，并且参考通道满足：

```text
Pref = k C(t)
```

其中 `k` 是已知常数，那么除以 `Pref` 可以精确消除 `C(t)`。云层遮挡、太阳高度变化
或集光效率缓慢变化，只有在它们对所有计算通道表现为同一个乘数时才属于这种情况。

### 4.2 不能消除什么

若第 `j` 个输入具有独立增益 `g_j(t)`，或第 `(i,j)` 个权重具有响应 `h_ij(t)`：

```text
P_i ∝ sum_j h_ij(t) g_j(t) W_ij u_j
```

单个 `Pref` 只能提供一个标量，无法恢复全部 `g_j` 和 `h_ij`。因此参考归一化不能
消除局部阴影、通道匀光误差、权重色散、探测器不匹配或正负臂失衡。

### 4.3 必要工程条件

- 参考、正轨和负轨必须**同时采样**；顺序曝光会把天气变化混进差分结果。
- 参考光路必须和计算光路共享集光、滤光和主要温漂路径。
- 参考探测器必须保持在线性、非饱和、正信号区域。
- 参考归一化后的尺度仍需通过已知的 `alpha`、`beta` 和参考增益 `k` 恢复。

## 5. 宽带日光的严格模型

真实探测器积分的是波长而不是单一标量。一般形式为：

```text
P_i(t) = sum_j integral S_j(lambda,t)
                         T_ij(lambda,t)
                         R_i(lambda,t)
                         u_j d_lambda
```

其中：

- `S_j`：第 `j` 个输入位置的日光谱功率；
- `T_ij`：输入调制器、扇出和权重单元的联合透射；
- `R_i`：探测器及其前置滤光的光谱响应。

只有当它能近似因式分解为：

```text
S_j(lambda,t) T_ij(lambda,t) R_i(lambda,t)
≈ C(t) s0(lambda) q_ij(lambda)
```

且积分后的 `q_ij` 在工作期间稳定时，系统才等价于一个固定有效矩阵。太阳光谱形状、
器件色散或通道响应若随时间改变，得到的是 `M_eff(t)x`，单个参考通道不能把它恢复成
固定的 `Mx`。

当前代码的 `spectral_weight_error` 只表示选定滤光条件下，每个权重的**波长积分等效
固定误差**。它不是逐波长传播模型。真实滤光片选型必须等以后加入 `S(lambda)`、
`T(lambda)`、`R(lambda)` 数据后再做。

## 6. 为什么这里不需要相干性

该处理器依赖功率相加，不依赖光场相位。探测积分时间内，不同通道的干涉交叉项应当
平均到足够小。宽带、多模日光通常有利于这一点。

但“日光非相干”不能被当成绝对保证：窄带滤光、单模耦合或路径高度匹配可能提高互相干
程度，产生条纹或散斑。真实装置应通过宽带工作、扩散片、多模混合、路径扰动和实测
对比检查，确认干涉交叉项低于目标精度。

## 7. 双轨光学布局

每个逻辑输入包含 `u+`、`u-` 两个强度通道。每个权重包含 `W+`、`W-` 两个非负
透过率。对第 `i` 个输出，需要两只同时工作的探测器：

| 探测器 | 汇聚的乘积 |
|---|---|
| 正轨 `P_i+` | `W_ij+ u_j+` 与 `W_ij- u_j-` |
| 负轨 `P_i-` | `W_ij+ u_j-` 与 `W_ij- u_j+` |

一个直接的自由空间实现是在二维调制平面上为每个 `(i,j)` 放置四个子像素，再用柱面
透镜或微透镜阵列把同一输出行汇聚到成对光电二极管。所有四类乘积必须来自同一次曝光。

硬件代价是约四倍权重单元和两倍输出探测器；这是任意四象限实数运算换来的确定性开销。

## 8. 三种硬件实现等级

### 8.1 全被动固定算子

- `M`：印刷灰度片、金属薄膜或固定透射掩模；
- `x`：自然场景、静态透明片或其他光学传感输入；
- 输出：保留为双轨光功率，或由零偏光电二极管读取。

无源光学核心可不需要外部电力，但矩阵不可动态修改，数字输出通常仍需要电子读出。

### 8.2 固定矩阵、可编程输入

- 固定权重掩模保存 `M`；
- LCD、DMD 或其他强度调制器写入 `x`；
- 适合固定模型推理或固定变换。

这一级需要输入调制器驱动、探测器前端和控制电路。

### 8.3 全可编程处理器

- 一块调制器编码输入；
- 另一块 SLM 编码权重；
- TIA、差分、参考归一化和 ADC 输出数值。

这是当前软件 API 最接近的硬件形态，也是用电最多、校准最复杂的一种。它仍然可以把
乘法和空间累加留在光学域，但不能称为“零耗电计算”。

## 9. 用电与能量边界

| 部件 | 外部用电 |
|---|---|
| 日光、固定透镜、滤光片、扩散片、固定掩模 | 可无源 |
| LCD/DMD/SLM 及其驱动 | 需要 |
| 零偏光电二极管 | 可由光产生电流，但实用读出仍需外围电路 |
| TIA、差分电路、参考除法、ADC | 需要 |
| 温控、太阳跟踪、自动校准 | 通常需要 |

当前模型使用归一化功率单位，没有瓦特、曝光时间、调制器能耗或 ADC 能耗，不能计算
J/MAC。后续只有建立绝对光功率和完整电气功耗清单后，才能比较日光、激光和电子方案。

## 10. 精度与光子预算

若只考虑泊松散粒噪声，探测到 `N_gamma` 个光子时：

```text
SNR ≈ sqrt(N_gamma)
```

理想情况下，约 `b` bit 的相对分辨率至少要求量级：

```text
N_gamma ≳ 2^(2b)
```

这是乐观下界。双轨结果接近零时，两个较大功率相减，定义消减因子：

```text
kappa = (P+ + P-) / |P+ - P-|
```

`kappa` 越大，相对误差越容易被放大；再加上参考通道噪声、暗电流、杂散光和量化误差，
实际需要的光子数会更高。因此实验评价应同时报告绝对误差、满量程误差和消减因子，
不能只在真实结果接近零时报告相对误差。

## 11. 校准流程

建议按以下顺序表征真实原型：

1. **暗场**：遮光测量每只探测器的偏置和读出噪声；
2. **参考线性度**：扫描照度，确定参考、正轨、负轨的非饱和范围；
3. **输入平场**：逐通道打开单位输入，测量 `g_j`；
4. **权重 LUT**：逐单元扫描灰度码，建立指令到有效透过率的查找表；
5. **双轨平衡**：同一单位权重分别走正负路径，表征差分臂失配；
6. **光谱检查**：至少在多个带宽或太阳模拟器谱形下重复矩阵表征；
7. **端到端矩阵**：用基向量逐列测量 `M_eff`，再用未参与校准的随机向量验证；
8. **户外复测**：跨照度、云量、太阳高度和温度检查误差是否仍在验收范围。

静态校准不能消除曝光期间变化的局部遮挡、谱形漂移或独立探测噪声。

## 12. 软件实现与物理边界对应

`IncoherentSolarProcessor` 把处理链显式拆成三段：

```python
powers = solar.optical_powers(x, ideal=False)  # 无源光学传播：P+、P-、Pref
observed = solar.detect(powers, ideal=False)   # 光子计数与探测/参考读出噪声
y = solar.decode(observed, normalize=True)    # 差分、参考归一化、标度恢复
```

便捷接口只是组合：

```python
y = solar.read(x, ideal=False, normalize=True)
```

这层分离具有两个目的：

- 防止把探测器噪声错误地注入光传播域；
- 允许把真实硬件测得的 `P+、P-、Pref` 封装为 `SolarPowerReadout` 后复用同一解码器。

参数与物理意义：

| 代码参数 | 物理代理 | 当前限制 |
|---|---|---|
| `irradiance` | 平均参考光功率标度 | 归一化单位，不是瓦特 |
| `common_fluctuation` | 每次曝光公共照度变化 | i.i.d.，无时间相关 |
| `spatial_nonuniformity` | 固定输入通道增益 | 未建二维匀光场 |
| `spectral_weight_error` | 固定波长积分权重误差 | 非逐波长 |
| `differential_gain_error` | 固定正负探测臂增益差 | 未建非线性和饱和 |
| `photons_per_unit` | 泊松光子计数换算 | 未从波长、功率、时间推导 |
| `detector_noise`、`reference_noise` | 背景扣除后的加性读出噪声 | 未分解 TIA、暗电流和 ADC |

## 13. 实验阶段与验收条件

### 阶段 A：软件与代数

- 任意实矩阵、实输入、偏置和批量输入与 NumPy 一致；
- 所有探测前功率非负，所有编程透过率在 `[0,1]`；
- 公共照度变化在无噪声条件下被参考通道精确消除；
- 固定通道误差和动态探测噪声具有不同、可测试的统计语义。

### 阶段 B：受控非相干光源台架

- 先用 LED 或太阳模拟器，不直接进入户外；
- 验证双轨、参考归一化、线性区和校准流程；
- 报告基向量测得的 `M_eff`、随机向量误差和重复性。

### 阶段 C：真实日光

- 同时记录参考照度、谱形代理、温度和天气；
- 比较归一化前后误差；
- 单独分析公共波动、空间不均匀和光谱变化；
- 只有跨条件重复结果稳定后，才讨论有效 bit 或能效。

## 14. 当前不做的工作

- 不为日光后端制作动画或 GIF；
- 不把日光模型塞进相干 MZI 类；
- 不声称零耗电、商用精度、TOPS 或能效优势；
- 不在缺少逐波长器件数据时选择真实滤光片；
- 不用理想浮点一致性代替硬件证据。
